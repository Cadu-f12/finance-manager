# personal-finance-manager
A simple personal financial management project

# How to run the project?

**The project isn't finished yet; for now, all we can do is set up the database with the user and the database itself.**

1. Setup the project
```bash
./run.sh setup
```

2. Fill in the environment variables
```bash
nano .env
```

3. Run the project
```bash
./run.sh up
```
